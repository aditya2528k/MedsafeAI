# 🏥 MedSafeAI – AI Medical Health Assistant

## 📌 Description
MedSafeAI is a simple AI-based web application that predicts possible diseases based on user-input symptoms using machine learning.

## 🚀 Features
- Symptom-based disease prediction
- User-friendly web interface
- Stores prediction history
- Fast and lightweight

## 🛠️ Technologies Used
- Python
- Flask
- Scikit-learn
- SQLite
- HTML/CSS
